# 塔塔助手 1.2.5

首次使用先运行 Setup.bat，自动配置模拟器和 Python。之后双击“启动.bat”。

巡访：打开游戏“找朋友”，导入名单，选择继续进度、起始序号或起始 ID，然后开始。支持只检查礼盒或自动领取。
钓鱼：打开钓鱼页面，选择次数后开始。截图、提竿、QTE、收鱼均通过 MuMu 后台控制，不占用电脑鼠标。
未知面板：短暂等待后点击游戏底部继续，最多补点三次；恢复钓鱼页后自动继续。仍无法恢复时保存诊断并停止。
停止：按 F8 或点击页面“停止”；关闭网页不会停止任务。
记录保存在 data 文件夹。排查问题可导出诊断包。

钓鱼效率：界面显示本次平均速度（竿/分）、运行时长和已确认竿数。等待咬钩、QTE、翻页均计入运行时长。每 10 秒记录一次，停止时保留最终汇总。速度明细位于 data/fishing/logs/每次运行目录/speed.csv，session.json 也保存最终平均速度。
